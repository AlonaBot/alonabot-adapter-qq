## Added

- Official QQ Bot API adapter for groups, C2C chats, channels and channel DMs, with Webhook and WebSocket transports.

- Official QQ logo from Tencent’s QQ website, included unchanged in component archives and the store listing.
- Build against the latest AlonaBot SDK v0.4.0.
